# Белот

Онлайн белот за четирима приятели. Отваряш линка, пишеш име, сядаш на едно от четирите места и играта започва, когато масата е пълна. Сървърът държи цялото състояние, така че никой не вижда чужди карти.

## Локално стартиране

Изисквания: Node 22+, pnpm 10 (`corepack enable`).

```bash
pnpm install
pnpm dev        # сървър на :3000, клиент (Vite) на :5173 с прокси за /socket.io
```

Отворете четири таба на `http://localhost:5173`, всеки с различно име. За производствен билд:

```bash
pnpm build      # apps/client/dist + apps/server/dist/index.js
pnpm start      # един Node процес сервира клиента и WebSocket-а на PORT (по подразбиране 3000)
pnpm test       # Vitest: engine, server, client
```

## Безплатен хостинг в Render

Проектът съдържа `render.yaml` за безплатен Web Service (без карта).

1. Качете репото в GitHub (публично или частно).
2. В [dashboard.render.com](https://dashboard.render.com) изберете **New → Blueprint** и посочете репото. Render чете `render.yaml`: `npm install -g pnpm@10.17.1 && pnpm install --frozen-lockfile && pnpm build`, стартира с `pnpm start`, health check на `/healthz`, план **Free**.
3. Изчакайте първия билд (2–4 минути). Адресът е `https://<име>.onrender.com`. Не задавайте `PORT` ръчно, Render го подава сам.
4. Споделете линка на стаята (`/r/КОД`) с приятелите си.

Какво да знаете за безплатния план:

- След 15 минути без трафик процесът спира и първият посетител чака 30–60 секунди. Всички стаи се губят, защото състоянието е само в паметта.
- `autoDeploy` е изключен нарочно: всяко ново качване рестартира сървъра и прекъсва текущите игри. Пускайте deploy ръчно от Render между игрите (**Manual Deploy → Deploy latest commit**).
- Един инстанс, 512 MB RAM. Напълно достатъчно за няколко маси.

## Правила (българска версия, като в Belot на Fortegames)

- 32 карти, четирима играчи в два фиксирани отбора (срещуположните места), раздаване и игра обратно на часовниковата стрелка.
- Раздават се 5 карти, наддаване, после още 3. Наддаването започва от играча вдясно от раздаващия.
- Ред на договорите: спатия < каро < купа < пика < без коз < всичко коз. Контра само от отбора, който не държи договора; реконтра само от отбора с договора след контра. Три поредни паса след обявен договор приключват наддаването; четири паса без договор – ново раздаване.
- Козови карти: J 20, 9 14, A 11, 10 10, K 4, Q 3. Некозови: A 11, 10 10, K 4, Q 3, J 2. При без коз точките се удвояват.
- Задължения: винаги се отговаря на боята. При игра на цвят се цака само ако противникът е с най-силна карта; на коз се качва задължително. При всичко коз се качва винаги, когато е възможно. При без коз няма задължение освен отговаряне на боята.
- Анонси: терца 20, кварта 50, квинта+ 100, каре 100 (10/Q/K/A), каре 9 150, каре J 200, белот 20. Няма анонси при без коз. Печели ги само отборът с по-силния анонс.
- Точкуване: закръгляне на 6 при цвят, 5 при без коз, 4 при всичко коз. Ако обявилият отбор има по-малко точки, всичко отива при противника (вътре). При равенство точките на обявилия висят за следващото раздаване. Контра удвоява, реконтра учетворява. Валат носи 90 точки бонус, но игра не се печели с валат.
- До 151 точки.

Спорните домашни правила (прагове на закръгляне, бонус за валат, качване на коз при партньор) са настройки в `packages/shared/src/engine/config.ts`.

## Структура

```
packages/shared   правила на играта (чист TypeScript, без зависимости) и протокол клиент–сървър
apps/server       Express + Socket.IO, стаи, места, авторитетно състояние на играта
apps/client       React + Vite, интерфейс на български
```
